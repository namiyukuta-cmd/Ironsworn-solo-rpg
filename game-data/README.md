## Public repository policy

このリポジトリでは、TRPGのゲームデータについてはGM用情報・秘密・伏線・未確定情報も含めて公開ミラーしてよい。

ただし、パスワード、APIキー、GitHubトークン、住所、メールアドレスなど、ユーザー本人の個人情報・認証情報はゲームデータへ保存しない。

Webアプリの `index.html` からは参照していません。ゲーム画面とは独立したAI用データ置き場です。
