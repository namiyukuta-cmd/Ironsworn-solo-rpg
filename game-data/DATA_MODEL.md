# Ironsworn data model

このリポジトリでは、ゲームデータを次の3種類に分ける。

## 1. 世界データ — `worlds/`

キャラクターとは独立した、その世界そのものの情報。

- 世界設定
- 地理・地域
- 都市・村
- 文化・宗教
- 勢力
- 世界固有ルール
- 世界の現在状態
- キャラクターの行動の結果として世界に残った変化

`worlds/index.json` が世界一覧とキャラクター／プレイの紐づけを管理する。

現在:
- `world-001` = 白金の世界
- `world-002` = ヒマリの世界

## 2. キャラクターデータ — `saves/characters/`

キャラクター自身の現在値。iPhoneキャラクターシートの「セーブ」が主に更新する領域。

- 能力値
- Health / Spirit / Supply
- Momentum
- XP
- アセットと取得能力
- 刺青など固有能力
- キャラクターシート上で管理する現在値

世界との紐づけはここへ埋め込まず `worlds/index.json` と `plays/index.json` に置く。これによりキャラクターの自動セーブで紐づけが消えない。

## 3. プレイデータ — `plays/`

そのキャラクターで実際に何が起きたかというキャンペーン／冒険の記録。

- 現在地
- Scene / Turn
- 現在の目的
- 誓い・進行中の課題
- キャラクターが行ったこと
- 判定と結果
- NPCとの出来事
- 発見
- 未解決の伏線
- GM進行状態
- 時系列の履歴

プレイの結果、世界そのものが変わった場合は、その結果を対応する `worlds/<world-id>/state.json` にも反映する。

## 関係

```text
world-001 ── 白金 ── play-shirogane
world-002 ── ヒマリ ── play-himari
```

白金とヒマリは別世界であり、世界データ・プレイデータを共有しない。
