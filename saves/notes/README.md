# Character free notes

キャラクターシート右下の自由メモ欄をGitHubへ保存する領域。

保存規則:
- `saves/notes/<character-id>.json`
- 例: 白金 → `saves/notes/shirogane.json`
- 例: ヒマリ → `saves/notes/char-1787151491684.json`

内容は持ち物、特性、性格、外見、個人メモなど用途を固定しない自由記述。
キャラクターの数値・アセット等は `saves/characters/` を参照する。
白金固有の刺青の定義は `saves/characters/shirogane-tattoos.json` を参照する。
